## 4. `⋯` 与历史

- 头栏: 左 = 身份 (整块可点 = 开新对话), 右 = 黄点 / 「历史」/ `⋯`;
- `⋯` 复用 `#lwp-drawer` 的 `menu` 态: 判断层 / 工作 / 收起, 进面板顶上一行「‹ 返回」;
- 历史窗 `#lwp-history`: 外壳照预览窗 (居中 / 左右 20dp / 高封 78% / 圆角 28 / 遮罩 40%), 内容 =
  搜索框 + 列表 + 底部「开始新的对话」;
- 数据 = `ctx.sessions.list` 的快照, 纯函数 `historyRows(snapshot, query, currentId)`:
  搜索框空着时**当前那场置顶**, 一输字就严格过滤 (标题或 id 尾巴, 不区分大小写); 空白场不进列表;
  `updatedAt` 倒序, 没有时间的沉底; 标题回退「新对话」;
- 点一行 → 关窗 + `follow(id)` (现有"先轻后重 + 跨工作区"), 打不开时只留一句 note、**不动当前场**。

## 5. 预设把口径说死 (主人这一轮的定法)

- 图: `lw_say` 的 `image` 参数 (绝对路径) —— 宿主**复制一份副本**, 相册里那张后来动了不影响;
- 表情: 一律 `lw_say({ sticker: "文件名" })` —— 只**引用** `lw/stickers` 里那一张, 不复制;
- `lw_sticker` **只在列素材时用 `op=list`**, 它的 `op=say` 是宿主底层 (球的回复框那条路), 不直接调;
- 两份预设 (luwi / proactive) 与 `lw_say` / `lw_sticker` 的工具描述同一套说法。

## 8. 已知边界

- 历史列表只画 `ctx.sessions.list` 里**已经加载**的那些 (dsh 自己的会话表), 别的工作区没打开时看不到;
  点开那种会话会走 `follow()` 的换工作区那条腿, 失败只留一句 note;
- 搜索一输字就严格过滤, 当前那场也可能被滤掉 (它不是"历史", 只是"最上面那一场");
- 昵称只影响对话层, 不动 dsh 的会话标题与球;
- `⋯` 的收起判据是"点到它自己与那颗按钮之外" —— 面板里的按钮不会把它关掉。
