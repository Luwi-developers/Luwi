# 更多设置去群味 方案 (2026-11-10)

## 0. 一句话

Luwi 只有**单聊**, 而「设置 → 活动 → 更多设置」里有 **14 项**是从 QQ 群桥接的 `socialV2` 抄过来的:
**9 项"什么算一次唤醒"在单聊里语义本身不存在**, 另 **5 项是两个整段死键**(「等待与静默」3 + 「唤醒时带多少」2).
撤掉这 14 项, 这一页只留真有读者的四类东西, 页面上的每一行都确实改得动行为.
顺带把「潜水与唤醒」这个**分组标题**改成「主动程度」—— 那 14 项走了以后, 这一段剩下的全是"她多主动、
隔多久来敲一次", 没有一处还是"唤醒" (见 §4.1).

## 1. 口径: 主人这一轮定的

> luwi 不是群, 而是私聊, 且只能私聊.

照这条, 三件在群里成立, 在单聊里不成立的事:

| 群里的问题 | 为什么群里有 | 单聊里为什么没有 |
| :-- | :-- | :-- |
| 哪条消息算"在叫她" | 一屏几十个人说话, 得判 @ / 点名 / 提问 / 拍一拍 | 你一开口就是对她说的, 没有"要不要算"这一层 |
| 叫太多次要限流 | 群里被 @ 十几次, 不拦会刷屏 | 单聊里频次就是你自己的说话频次 |
| 唤醒时截多少历史 | 群消息太多, 只能捞最近 N 条塞进去 | 会话本身就是上下文, 由 dsh 的会话承载 |
