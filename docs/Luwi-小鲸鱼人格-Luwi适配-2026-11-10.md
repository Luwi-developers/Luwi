## 1. 6000 字是 QQ 桥接的闸, 不是 Luwi 的

| 数 | 在哪 | 是什么 |
| :-- | :-- | :-- |
| **6000 字符** | `qq-bridge` 的 `role.maxInjectChars` (1000~20000) | 桥接**每条消息**注入人格卡时的截断上限; 小鲸鱼原卡 5946 字, 卡着这个数写的 |
| 无校验 | dsh 的 persona 插件 | `prefix` 收多长都行 |
| **20000 字符** | Luwi `lw_persona` 的写入口 | 卡的上限 (再长就是把每一步的上下文烧掉); 超了 `write` 拒, 读到超长的旧卡会截断并写明 |

Luwi 这边没有 6000 这道闸; 卡有多长只看上下文预算。

## 2. 现在的结构: 守则静态, 人格卡运行时读

```
presets/luwi/cordis.patch.yml  persona.prefix (约 2500 字, 静态)
├── 一~六、守则        说话 / 工具 / lw_say / 图与表情 / 红线 / 看屏
└── 七、她是谁
        {{lw_persona}}          ← 每一步组提示词时求值
                ↑
host-plugin 的 prompt 变量 `lw_persona`
                ↑ 按 mtime + size 缓存
$DSH_HOME/lw/persona/xiaojingyu.md        ← 人在设备上改 (lw_persona op=write)
                ↑ 读不到时
包内默认 `node_modules/luwi-channel/persona.txt` (由 pack-host 从 presets/luwi/persona/xiaojingyu.md 拷)
                ↑ 再读不到
四行兜底 (称呼 / 短 / 不编 / 看屏)
```

| 层 | 在哪 | 每轮进上下文吗 | 谁改 |
| :-- | :-- | :-- | :-- |
| 守则 | `presets/luwi/cordis.patch.yml` 的 prefix | 是, 全文 | 改预设 (要出包) |
| 人格卡 | `$DSH_HOME/lw/persona/xiaojingyu.md` | 是, 全文 (变量展开) | **设备上说一句 / `lw_persona`** |
| 卡源 | `presets/luwi/persona/xiaojingyu.md` | 否 (它是包内默认与仓库副本) | 改仓库 (要出包) |

**为什么不是"卡全文烘进 prefix"**: 那样改一个字就要重出包; 运行时读卡之后, 改卡只是写一个文件。

## 3. 改人格的三条路

| 场景 | 做法 | 生效 |
| :-- | :-- | :-- |
| 日常 (最常用) | 在 Luwi 里说「以后别叫我主人，叫我名字」→ 她调 `lw_persona op=write` | **下一次模型请求** |
| 想看一眼 / 整份替换 | `lw_persona op=read` / `op=write` (参数 `text`) | 同上 |
| 改坏了 | `lw_persona op=reset` (回到包内默认) | 同上 |
| 开发机整份手推 | `pwsh -File tools\lw-persona.ps1 -Source <卡文件>` | 下一次请求 |

- 写入口会先备份旧卡到 `xiaojingyu.bak.md`, 原子写 (tmp + rename), 写完读回逐字比对; 每次写往
  `$DSH_HOME/lw/persona/audit.jsonl` 记一行 `{at, op, chars, session}` (不记正文)。
- 模型侧规矩写死在工具描述里: **只有主人明确说要改人格 / 改称呼时才写**。

## 4. QQ 版 -> Luwi 版: 改了什么

| QQ 卡里的 | Luwi 这边 | 为什么 |
| :-- | :-- | :-- |
| 群友 / 群文化自适应 / 引用与抢话 / 潜水与唤醒 / 冷场抛话题 | **删** | 这里只有主人一个人; 潜水与唤醒由 `sim.json` 与 30 分钟闸管 |
| "不叫主人、不玩女仆 / 服从梗" | **改**: 叫他主人 (他定的称呼), 但**不演女仆 / 服从** | 那句原本防的是群友玩梗 |
| 每条消息 1~10 字 / 分条 | 保留在守则; 分条由 `lw_say` 的 `lines` 实现 | 通道不同, 规矩同源 |
| 表情包 / 看图 | 改成 `lw_say` 的 `sticker` / `image` | Luwi 的通道只有这两个 |
| 白饭 / 爹梗 / 中转站 / 上班迟到 | 保留为**低频彩蛋**, 一场最多一次 | 私聊里玩多了像在演群聊 |
| AI 味黑名单 | 保留; 删群聊项 | 私聊照样怕客服腔 |
| 傲娇嘴硬 / 心软藏着 / 偶尔摆烂 / 正事靠谱 / 查资料多搜几步 | 保留 | 小鲸鱼的骨 |
| "默认睁眼、不承认别的二创" | 保留 | Luwi 随包就是鲸鱼娘外观 |

**新加 (QQ 卡里没有)**: 看屏只判断不转述 (守则第 25 条)、主动场说完就停 (守则第 22 条)。

**老安装怎么拿到新结构**: 预设声明原来是"行在就不动", 所以旧机器永远收不到正文改动。现在
`CustomPresets` 按 `# lw-preset:` 标记对账: 标记不同就把那条声明整条换掉 (替换前把 patch 备份成
`cordis.patch.yml.bak-before-preset-refresh`)。以后改预设正文, **抬一版标记**就能到老机器。
