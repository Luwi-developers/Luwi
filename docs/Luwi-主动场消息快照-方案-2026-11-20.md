## 二、快照怎么来的

### 取哪一场

`portalSnapshotTarget()`: `voiceCurrentSession()` (账本 30 分钟窗口, 内含 cwd 校验) → 为空则读 `$DSH_HOME/voice/session.json` 原文的 `id` (过期也认一次, 与门户 `staleFollowed` 同口径) → 都没有就不注入。

### 两条来源

| 来源 | 怎么取 | 取什么 |
| :-- | :-- | :-- |
| **他的话** | `sessionController.resolveAgent(id)` → `session.snapshotEvents()` + `deriveEventMessage()` | 只认 `role === 'user'`; 时间取事件的 `time` |
| **她的话** | `$DSH_HOME/lw/out/<id>.jsonl` | `kind` 为 text / image / file / sticker 的行; `assistant` 正文**不取** (门户也不画正文) |

合并 → 按 `at` 升序 → 取**最后 20 条** → 输出时反转成**新→旧**。

### 附件「允许读取」

- **他的附件**: 门户与浮标发送时已落进工作区 (`lw-in/` / `.lw-inbox/`), 路径就在正文里 → 不搬, 原样带出。
- **她的图与文件**: 落在 `$DSH_HOME/lw/out/assets/<id>/`, 主动场读不到 (沙箱在工作区) → 复制到 `<工作区>/.lw-snapshot/<id>/`, 行里给工作区相对路径 `/.lw-snapshot/<id>/<名字>`。
- 复制失败或单张 > 8 MB → 行里写「（图没取到）」, 不静默丢。

### 预算

| 常量 | 值 | 作用 |
| :-- | :-- | :-- |
| `PROACTIVE_SNAPSHOT_ROWS` | 20 | 最多几条 (主人点名) |
| `PROACTIVE_SNAPSHOT_CANDIDATES` | 60 | 往回最多翻这么多条才凑满 |
| `PROACTIVE_SNAPSHOT_ROW_CHARS` | 200 | 单条截断 (粘代码不撑爆) |
| `PROACTIVE_SNAPSHOT_MAX_CHARS` | 4000 | 整段硬上限, 从最旧开始丢 |

## 三、注入的形状

`proactiveStartLine(text, summaryPath, acting, snapshot)` 的第 4 个参数; 位置在「启动顺序 / 摘要路径」之后、**档位权限之前**:

```text
本次消息快照: 门户里最近 20 条 (新->旧), 先看这个再决定开口; 带路径的图 / 文件可以直接读, 不用先问.
1. [21:04] 你: 先吃饭吧, 别熬太晚
2. [21:03] 他: 刚才那个拖放的问题我还在看 [图 /.lw-snapshot/<id>/3-a.jpg]
...
快照里出现的验证码 / 密码 / 金额 / 地址, 你看见了也当没看见: 不念出来, 也不抄进文件.
```

`snapshot` 为空串时**整段 (含头尾两句) 都不出现** —— 于是 2 参 / 3 参调用的输出逐字不变 (判据钉着)。

## 四、失败模式

| 情况 | 行为 |
| :-- | :-- |
| 没有账本 / 没有 `DSH_HOME` | 不注入 |
| 那一场 `resolveAgent` 抛错 (已归档 / 不在当前工作区) | warn 一行, 只取 `lw/out` 那一半 |
| 两边都空 | 不注入, 但**留一行读数** (`portal snapshot source her=0 his=0`) —— "没出现"与"读不到"在日志里必须分得开 |
| 那一场正在跑 | 只读派生消息, 不 steer、不打断 |
| 快照构建整体抛错 | `startProactive` 里 catch + warn, 开场照旧发出去 |
