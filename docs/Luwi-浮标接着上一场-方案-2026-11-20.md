# 浮标接着上一场：窗口 10 → 30 分钟、回复框与门户都续期、指代词带屏过去（2026-11-20）

主人原话：**"当我在浮标发送有带这个之类的词时会直接开新会话，而没有回复上一次会话，应该带图回复，而不是
重新开新会话"**，随后两条口径：**"10min改为30min"**、**"'框开着、里面已经有她推来的一条回复，你在下面回'
这个要续期"**、**"每一次门户发送都 portalBind 续一次"**，以及当晚又一条：**"要求 ball 对话也投到 luwi
工作区，不再投到 dsh-ball 了"**（见第七节 —— 本文正文里出现的 `dsh-ball` 一律读作"浮标那条工作区"，即
`Luwi`）。

## 一、现场读数（真机 OJZD5D6TMNSKFYHM，改前）

```
voice/session.json   {"id":"session-77a0b19e-…","at":1795162161041,"origin":"ball","cwd":"/storage/emulated/0/DSH/dsh-ball"}
lw/voice-inbox.json  delivery: {lines:3, opened:2, reused:0, origin:"ball",
                                why:"the hour was up, so the wake word opened a new conversation"}
                     ledger:   {usable:true, cwd:"/storage/emulated/0/DSH/dsh-ball"}
voice/inbox.jsonl    seq14 12:32:53 / seq15 14:07:03 / seq16 14:12:25 / seq17 16:09:20（全 voice + wake）
```

三条根因，都不是"这个"这个词本身：

1. **换场由 `VOICE_SESSION_MS`（10 分钟）说了算**：两次开口隔近 2 小时 → 候选清单空 → `openBallConversation`
   新开一场（`opened: 2/3`）。
2. **账本只认 `origin === 'ball'`**：① 从回复框接着回的那一句被认成 `replyBox`，不续期；② 门户那一侧只在
   这场**第一句**时 `portalBind` 一次，之后你在门户里聊多久都不再续 —— 两种都让"上一场"从账上消失。
3. **指代词附图（`autoScreenShot`）本身是好的，但图送错了地方**：句子含 `这个` / `这张` / `屏幕上` 时会截一张
   主屏挂成用户消息的图块，可它跟着"新开的那一场"进去 —— 她手里一张屏，却没有指代对象。

附带一条现实：当天 4 条语音的转写全是错字（«就行喽» / «后头，心率上后头»），靠词表认"这个"只能兜一半，
另一半必须靠"账本别再丢"。

### 账本续期的新判据

```js
const pointed = await voiceLedgerId()                                   // 账本现在指着谁
const landed = await canonicalVoicePath(outcome.cwd ?? '')
const inBall = voicePathUnder(landed, await canonicalVoicePath(ballWorkspace()))
const keepsLedger = origin === 'ball'
  || (origin === 'replyBox' && (String(sessionId) === pointed || inBall))
if (keepsLedger) await voiceSessionBump(sessionId, { origin, cwd: … })
```

`String(sessionId) === pointed` 那一支是给门户 `portalBind` 过来的**合流场**：那场真实 cwd 在 `Luwi`，账本
却（有意地）写着 `dsh-ball`，按落点认不出来，只能比 id。两条都不成立的 `replyBox`（框里挂着别的 GUI 场）
仍然**一个字节都不动** —— 2.7.8 根因二还在原地。

## 三、行为真值表

| 上一句之后 | 这一句从哪来 | 落点 / 账本 |
| :-- | :-- | :-- |
| ≤30 min | 球（点球 / 唤醒 / 空框） | 上一场，续期 30 min |
| ≤30 min | 回复框里接着回 | 那一场，续期 30 min |
| 任意 | 门户里每一句 | 投门户当前那一场，账本被 `portalBind` 挪到它并续期 |
| 30 min – 24 h | 含 `这个` / `刚才` / `改成` … | 上一场 |
| 30 min – 24 h | 普通一句话 | 新开一场 |
| > 24 h | 任意 | 新开一场 |
| 任意 | 框里挂的是别的 GUI 场 | 投那一场，账本不动 |
| 任意 | 那一场被删 / 非根会话 | 新开一场（`resolveAgent` 失败） |
| 含 `这个` / `这张` … | 任意 | 照旧附一张 display 0 截图，且现在落在同一场里 |

## 五、坑（下一眼别踩）

- **`SCREEN_REF_WORDS` 与 `REFER_BACK_WORDS` 不是一张表**：`屏幕上` / `照片里` / `这份` 指那块屏，带一张图就够，
  不需要把上一场接回来；两张表都必须有的是 `这个` / `这张` / `这个图` / `这张图` 那四条。
- **`portalBind` 把 `cwd` 硬写成 `dsh-ball` 是有意的**（2026-11 那批"两边看到同一个流"），于是"浮标的对话都在
  `dsh-ball` 里"本来就有一个显式例外；别把它改成"读会话真实 cwd"，那条合流当场断。
- **门户 `send()` 里 `portalBind` 在 `session.prompt` 之前**：那一句若被 dsh 拒（图片块被拒等），账本已经挪过去
  了。与改前同一条路，只把它写进注释。
- **`RECENT_PROACTIVE_MS` 仍是 10 分钟**：它是"刚才那一下说完没"的读数，不是账本窗口；2026-11-20 起两处
  不再是同一个数，别再按"同一个数"去改。
- **外部改 `voice/session.json` 不会立刻生效**：`voiceSessionLoad()` 读一次就只认内存那份 (`state.file.read`)，
  宿主起来之后不再看盘。验收"过期账本"那一档要么在**装机/重启 host 之前**把 `at` 改好，要么用真的一段时间
  间隔；2026-11-20 那次就是这样：改盘之后立刻投一句，宿主用的还是内存里刚写进去的 `at`。
- **判据拿不到 `@deepseek-ai/dsh-tools` 时 `check-host-plugin.mjs` 起不来**（本机常态）—— 那条是插件注册数下限，
  与本次改动无关，装完包在 host 树里跑。
## 七、同日改口径：浮标那条工作区从 `dsh-ball` 换成 `Luwi`

主人 2026-11-20 晚：**"要求 ball 对话也投到 luwi 工作区，不再投到 dsh-ball 了"**。

| 位置 | 改动 |
| :-- | :-- |
| `host-plugin/index.mjs` `BALL_WORKSPACE_NAME` | `'dsh-ball'` → **`'Luwi'`**（与探索 / 主动场同一个目录，`ensureChannelWorkspace` 的幂等 create 让两条注册路碰在同一个目录上） |
| `app/.../ui/PortalBridge.kt` `BALL_WORKSPACE` | 跟着改成 `"Luwi"`（判据 `check-luwi-portal` 逐字比对两端） |

三件连带的事，都必须知道：

1. **老的 `dsh-ball/` 目录留着不删**：里面的历史会话仍归那条工作区（侧栏那一行还在），只是不再往里投新话；
   想清理是主人自己的事，工具不主动删。
2. **账本的 cwd 判据跟着变成 `Luwi`**：`voiceLedgerUsable` 拿它比，于是升级后第一次投递会发现"老账写着
   `dsh-ball`" → 当没有 → 在 `Luwi` 开一场新的。这是预期的一次性代价，不是"上一场丢了"。
3. **`dsh-ball` 那条工作区的注册还在**（profile 里的 workspace 记录不会自己消失）；新会话不再进它，
   所以它会慢慢空下来。

判据：`check-voice-inbox` 75 条（`ballDir` 由 `api.ballWorkspace()` 现算，跟着变名字也不用改表）+
`check-luwi-portal` 738 条（两端常量一致那条会指出新的名字）。
