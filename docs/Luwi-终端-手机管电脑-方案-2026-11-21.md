# 终端 = 手机管电脑 (方案, 2026-11-21, 2.8.1 #48)

> 主人四条原话:
> ① 终端 (原同步) 改成仅由手机管理电脑, 电脑仅同步最新对话到手机上, 或手机上开新对话发送到 pc; luwi 的工作区
> 不再同步到 pc, pc 也不再允许控制 luwi
> ② 门户做个终端界面: 点终端时门户全变黑; 若还未连接 pc, 弹出弹窗 (扫码配对 / 返回), 点返回退出终端
> ③ 终端中头像强行改成 luwi 头像, 名称强行改成「luwi终端」; 点头像只显示最近 pc 会话; 新建会话仅新建与 pc
> 连接的会话; 非终端的历史不显示终端的历史, 终端的历史不显示非终端的历史
> ④ 后台 dshluwi 浮标中点击终端跳转这个终端页面

## 1 口径

- **终端 = 手机管电脑**: 手机把话发到电脑上执行 (对端通道 `/luwi-sync/send` + 插件的归属方闸),
  电脑只把**最近的对话**同步过来 (投影会话 + 进行中的回答; 会话基线窗口之外的老对话不进来)
- **工作区不再同步**: 手机不建工作区镜像源、不写工作区名片、也不把电脑的工作区文件物化到自己身上
- **电脑不能再控制手机**: 入站 `peer/send` 按 `peer.acceptSend` 拒; `peer.listen` 在控制器上关掉;
  面板写面 (`panel/op`) 与终端 (`panel/term`) 以及本机 `send` / `peer-live` 都只认**回环**
- **角色不靠 `pairing`**: 生成配对码的电脑保存仓库时**也会写** `pairing` (面板 `configureFromPanel`),
  所以"有 pairing = 手机"在电脑上同样成立, 会把电脑也关成不听不收。口径改成显式 `role`:
  手机扫码写 `role: "phone"`, 电脑面板保存/重新配对写 `role: "pc"`; 老配置没有这个键时退回
  "有 `pairing` **且** `peer.url` 非空 = 手机" (手机记着电脑的地址, 电脑那一侧没有)

## 2 数据面

`$DSH_HOME/lw/session-sync.json`:

```json
{
  "peer": { "listen": false, "acceptSend": false, "proxy": true, "url": "http://…", "token": "…" },
  "workspace": { "enabled": false },
  "pairing": { "v": 1, "id": "…", "at": 0, "from": "书房 电脑" }
}
```

- 写者只有两处: 应用 `SyncSetting.applyPairingIn` / `setSyncOnIn` (手机) 与插件 `luwi-configure.mjs` (电脑面板)
- 读侧 (`sync/SyncSetting.kt` 的 `Snapshot`) 与插件 (`resolvePeerSpec`) 同一套键; 老配置里没有 `listen` /
  `acceptSend` 时按"已配对 = 手机那一侧"推 (不听、不收指令)
- **口令只在文件里**: 门户那一页从 `PortalTerminal.status` 拿到的读数不含 token

## 5 门户那一页 (`presets/luwi-portal/lib/client.js`)

- 纯函数: `normalizeCwdPath` / `underShadow` / `terminalRows` / `terminalGateState` / `historyRows(…, scope)`

- 弹窗: `#lwp-term-gate` (黑底卡) 恒两颗钮 —— 「扫码配对」(`portalTerminalPair`)、「返回」(`closeTerminal`)

  把那些排除; 标题与底部按钮随之换文案

  第一句话由插件的归属方闸转给电脑 (`target:{kind:'new'}`), 回答折回同一场
