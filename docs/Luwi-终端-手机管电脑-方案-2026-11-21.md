# 终端 = 手机管电脑 (方案, 2026-11-21, 2.8.1 #48)

> 主人四条原话:
> ① 终端 (原同步) 改成仅由手机管理电脑, 电脑仅同步最新对话到手机上, 或手机上开新对话发送到 pc; luwi 的工作区
> 不再同步到 pc, pc 也不再允许控制 luwi
> ② 门户做个终端界面: 点终端时门户全变黑; 若还未连接 pc, 弹出弹窗 (扫码配对 / 返回), 点返回退出终端
> ③ 终端中头像强行改成 luwi 头像, 名称强行改成「luwi终端」; 点头像只显示最近 pc 会话; 新建会话仅新建与 pc
> 连接的会话; 非终端的历史不显示终端的历史, 终端的历史不显示非终端的历史
> ④ 后台 dshluwi 浮标中点击终端跳转这个终端页面

## 1 口径

- **终端 = 手机管电脑**: 手机把话发到电脑上执行 (对端通道 `/luwi-sync/send` + 插件的归属方闸),
  电脑只把**最近的对话**同步过来 (投影会话 + 进行中的回答; 会话基线窗口之外的老对话不进来)
- **工作区不再同步**: 手机不建工作区镜像源、不写工作区名片、也不把电脑的工作区文件物化到自己身上
- **电脑不能再控制手机**: 入站 `peer/send` 按 `peer.acceptSend` 拒; `peer.listen` 在控制器上关掉;
  面板写面 (`panel/op`) 与终端 (`panel/term`) 以及本机 `send` / `peer-live` 都只认**回环**
- **角色不靠 `pairing`**: 生成配对码的电脑保存仓库时**也会写** `pairing` (面板 `configureFromPanel`),
  所以"有 pairing = 手机"在电脑上同样成立, 会把电脑也关成不听不收。口径改成显式 `role`:
  手机扫码写 `role: "phone"`, 电脑面板保存/重新配对写 `role: "pc"`; 老配置没有这个键时退回
  "有 `pairing` **且** `peer.url` 非空 = 手机" (手机记着电脑的地址, 电脑那一侧没有)

## 2 数据面

`$DSH_HOME/lw/session-sync.json`:

```json
{
  "peer": { "listen": false, "acceptSend": false, "proxy": true, "url": "http://…", "token": "…" },
  "workspace": { "enabled": false },
  "pairing": { "v": 1, "id": "…", "at": 0, "from": "书房 电脑" }
}
```

- 写者只有两处: 应用 `SyncSetting.applyPairingIn` / `setSyncOnIn` (手机) 与插件 `luwi-configure.mjs` (电脑面板)
- 读侧 (`sync/SyncSetting.kt` 的 `Snapshot`) 与插件 (`resolvePeerSpec`) 同一套键; 老配置里没有 `listen` /
  `acceptSend` 时按"已配对 = 手机那一侧"推 (不听、不收指令)
- **口令只在文件里**: 门户那一页从 `PortalTerminal.status` 拿到的读数不含 token

## 5.1 补: 进终端落哪一场 / 退出回哪一场 (2026-11-21 主人三句话)

主人原话: 「进入终端时打开1h内最近终端对话，没有要新建终端对话，返回时恢复门户对话。」

- **落哪一场** (`terminalEnter`): 已经在电脑那几场里就**不动** → 否则 `terminalRecentRow(rows, now, TERMINAL_RECENT_MS)`
  取 **1 小时内 `updatedAt` 最大**那一场 (恰好 1 小时算在里面, 没时间的沉底) → **一场都没有就 `terminalNew({quiet:true})`
  新建一场与电脑连的对话** (静默那趟出的事由 `terminalNoteOnce` 一分钟最多说一句: 探针 5/15 秒一拍不许刷屏)
- **自动那趟 20 秒最多一次** (`TERMINAL_ENTER_COOLDOWN_MS`): 建不出来时别每个探测拍都重来一遍; 人自己再点一次
  头栏 / 球菜单「终端」时 `setTerminal` 把冷却清 0 (当场再试); 用户按的「在电脑上开一场新对话」与发送那一句
  仍走不带 `quiet` 的那条 (`send()` 里 `terminalNew()`)
- **窗口只决定自动落哪一场**: 1 小时外的几场仍在终端历史里, 点一下照样接着聊
- **退出终端之后那一趟作废**: 「新建」要等影子工作区 (40×250 ms) 再开一场, 中间人可能已经按了返回 ——
  `terminalNew` 里两道 `!terminalMode` 的闸 (等出工作区之后 / 等出新场之前) 把它掐掉, 否则 dsh 的 mainView
  会被人留在电脑那一场
- **退出回哪一场** (`terminalRestore`): 返回点由 `terminalReturnFor` 定 —— 屏上**本来就不是**电脑那一场就记它;
  屏上就是电脑那一场 (老记录没带 `back` / 在终端里重载过来的) 退 `SESSION_KEY` 里那一场; 两样都没有记空串
  (**绝不把电脑那一场记成返回点**, 记了"返回"等于没退); 同时写进 `localStorage['dsh.luwi.portal.terminal'].back`
  —— 页面重载 / 配对重启 host 之后由 `terminalReturnOf` 认回来 (认出是电脑那一场的老记录直接不认)
- **落地判据是 `terminalLanded` 不是 `switchTo` 的返回值**: 后者只是"画得上" —— 终端把 dsh mainView 带去了影子
  工作区, `openSession` 第一下必抛 `unknown session`, 那时 mainView 还在电脑那一场, 只判 `drawn` 会让下一拍
  会话表把门户再拽回去。所以补拍判的是"画上了 **且** mainView 不在电脑那一场" (`terminalLanded(drawn, main, id,
  isTerminalSession(main))`, 第 4 个实参看的是 mainView 那一场), **250 ms × 20 = 5 秒** (这一趟一定跨工作区,
  要等那趟 RPC 回来); 真换了场才 15 秒不跟账本
- **会话表那条跟随也两扇门互不串** (`listUnsub`): mainView 落在"另一种场"时不跟 —— 普通门户不跟电脑那几场,
  终端里也不跟回手机那一场
- **进终端之前门户还没落到任何一场 / 返回点空着** → 回门户那个默认工作区 (`landInDefaultWorkspace('back')`,
  画的那一场或 mainView 任一还挂在电脑场就算)
- **`SESSION_KEY` 不再记电脑那几场** (`adopt`): 记了之后重载 / 退出门户再进来, 门户自己会停在电脑那一场;
  在终端里退出门户 (`unmount`) 时, **只有 mainView 真在电脑那一场才切一次工作区** (影子工作区里的场
  `openSession` 一个都留不住, 而 `hide()` 刚在那儿开的空场会跟着被换掉) —— 尽力而为, 不给卸挂添会抛的路
- **静默那趟的说法是 `terminalNoteOnce`**: 同一句话一分钟最多一次, 换了一句 (另一种原因) 当场说 —— 黑底上
  5/15 秒一拍探针不许刷屏, 但也不能一声不响
